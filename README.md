# Hermes Multi-Agent Coordination Layer

Coordination infrastructure for existing [Hermes Agent](https://hermes-agent.nousresearch.com/docs) installations.

Hermes Agent remains the execution engine. This project is not an agent framework and does not implement agents, skills, reasoning loops, memory systems, prompts, tool routing, or model execution.

The Coordination Layer manages tasks, workflows, agent registration, assignments, notifications, approvals, artifacts, monitoring, and fleet operations across distributed deployments.
